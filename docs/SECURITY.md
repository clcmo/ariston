# Política de Segurança

## Versões com Suporte

Relatos de segurança são bem-vindos para a versão mais recente publicada a
partir de `main` e para a branch `main` atual. Versões mais antigas podem não
receber correções de segurança; se possível, atualize para a versão publicada
mais recente antes de relatar um problema.

## Como Relatar uma Vulnerabilidade

Relate vulnerabilidades de forma privada usando **Report a vulnerability** na
aba **Security** do repositório no GitHub:

https://github.com/clcmo/ariston/security/advisories/new

Não relate vulnerabilidades de segurança por meio de issues públicas, pull
requests ou outros canais públicos. Se o envio privado de relatos não estiver
disponível, entre em contato com os mantenedores pelo GitHub e solicite um
canal privado, sem incluir detalhes da vulnerabilidade na mensagem pública.

Relatos sobre o cliente Flutter, o Cloudflare Worker, a autenticação do
Firebase ou suas configurações devem incluir, quando possível:

- O componente e a versão ou commit afetados.
- Uma descrição do possível impacto e das etapas para reproduzir o problema.
- Uma prova de conceito mínima que não acesse nem modifique dados de outras
  pessoas.

Não inclua chaves de API, tokens de acesso, senhas, informações pessoais ou
conteúdo de conversas privadas no relato. Ao investigar uma possível
vulnerabilidade, não acesse, modifique nem divulgue dados de outras pessoas.

Os mantenedores analisarão os relatos e coordenarão diretamente com quem os
enviou a correção e a divulgação da vulnerabilidade. No momento, não há prazo
definido para resposta.
